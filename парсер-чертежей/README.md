# Парсер чертежей

Приложение разбирает PDF локально в браузере, сопоставляет количества из Excel, рассчитывает заготовки и формирует PDF со штампами. Внешние AI API и API-ключи не используются.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет сервер (по умолчанию `http://localhost:3000`). Для доступа с других устройств приложение нужно разместить на доступном им сервере; PDF обрабатывается в браузере пользователя.

## Распознавание PDF

PDF.js извлекает текстовый слой PDF. Для страниц без текстового слоя используется Tesseract.js с русской моделью, размещённой вместе с приложением; первая OCR-загрузка занимает около 11 МБ и затем кэшируется браузером.

Обозначение и наименование извлекаются из отдельных ячеек основной надписи (штампа) в нижнем правом углу чертежа. Если текстовый слой PDF не содержит одного из этих полей, локальный OCR читает штамп, даже когда на чертеже есть другой текст. Координаты учитывают поворот страницы. Результаты извлекаются эвристически, а не интерпретируются инженерной нейросетью, поэтому значения нужно сверять с исходным чертежом. Для сканов качество зависит от разрешения и читаемости страницы; значения, которые не удалось распознать, оставляются для ручной проверки. Excel можно использовать для внесения и сверки количеств.

Страницы после титульника «Прутки/шпильки» до следующего титульника сохраняются в исходном комплекте и итоговом PDF, но не показываются в таблице деталей и не участвуют в сверке с Excel.
